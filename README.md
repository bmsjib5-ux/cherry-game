# 🍒 น้องเชอร์รี่ผจญภัยแดนมอนสเตอร์

เกม 3D RPG ผจญภัยจับมอนสเตอร์ สร้างด้วย React + Three.js

🎮 **เล่นเลย:** https://bmsjib5-ux.github.io/cherry-game/

## ฟีเจอร์
- ⚔️ 3 สายอาชีพ: นักรบ / นักธนู / นักเวท พร้อมท่าไม้ตายเฉพาะตัว
- 🎀 แต่งตัวละคร: สีผิว ทรงผม ดวงตา ชุดเริ่มต้น
- 🐾 จับมอนสเตอร์เป็นสัตว์เลี้ยง วิวัฒน์ทุก 3 เลเวล ร่วมสู้ด้วยสกิลธาตุ
- 💥 สกิลธาตุ 5 ธาตุ + ระบบจุดอ่อน + อาวุธธาตุตามอาชีพ
- 🎁 อุปกรณ์ 7 ช่อง ตีบวก +5 ออร่าเรืองแสงตามธาตุ + เซ็ตมังกร 🐉
- 🏪 ร้านค้าซื้อ-ขายด้วยเหรียญทอง
- 🌗 กลางวัน-กลางคืน + 👻 บอสผีราตรี + ⏰ เหตุการณ์สุ่ม + 🗼 หอคอยมิติ 10 ชั้น
- 🤖 โหมด AUTO ล่ามอนสเตอร์อัตโนมัติ

## เทคโนโลยี
ไฟล์เดียวจบ (`index.html`) — React 18 + Three.js r128 ผ่าน CDN ไม่ต้อง build
